# Exercícios em C 💻

Este repositório contém exercícios básicos desenvolvidos em **C**, com o objetivo de praticar e reforçar os principais conceitos da linguagem e da lógica de programação.

## 📚 Conteúdos

Os exercícios abordam conceitos como:

* Entrada e saída de dados
* Variáveis e tipos de dados
* Operadores aritméticos e lógicos
* Estruturas condicionais (`if`, `else` e `switch`)
* Estruturas de repetição (`for`, `while` e `do while`)
* Vetores e matrizes
* Funções
* Ponteiros
* Strings
* Structs

## 🚀 Como executar

Para compilar um arquivo utilizando o **GCC**:

```bash
gcc arquivo.c -o programa
```

Depois, execute o programa:

### Linux / macOS

```bash
./programa
```

### Windows

```bash
programa.exe
```
